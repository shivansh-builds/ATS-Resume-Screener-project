# 📄 ATS Resume Screener

An **ATS (Applicant Tracking System) Resume Screener** that analyzes a candidate’s resume and determines whether they are fit for a given job role.

This project mimics how real-world ATS systems work by comparing resumes with job descriptions using **Machine Learning, Data Science, and NLP techniques**.

---

## 🚀 Project Description

Recruiters often receive a large number of resumes for a single job opening. Manually screening them is time-consuming.  
This ATS Resume Screener automates the initial screening process by analyzing resumes and scoring candidates based on job requirements.

I personally tested this system using my **first-year resume** and received a **1/10 score**, as the job required **at least 5 years of experience**. This confirms that the model evaluates experience realistically.

---

## 🧠 Features

- Resume analysis using NLP  
- Job description matching  
- Candidate scoring based on relevance  
- Fit / Not Fit decision  
- Experience-aware evaluation

## ⚙️ How It Works

1. Input the candidate’s resume  
2. Input the job description  
3. Preprocess the text data  
4. Compare resume and job description  
5. Generate a fit score  
6. Output whether the candidate is **fit for the job or not**
